ETAPE A — METTRE LE JEU EN LIGNE (GitHub Pages)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Va sur https://github.com
2. Clique sur "Sign up" (créer un compte gratuit)
   → Utilise ton adresse Gmail
   → Choisis un nom d'utilisateur simple
     exemple : kais-odz

3. Une fois connecté, clique sur le "+" en haut à droite
   → Clique sur "New repository"

4. Dans "Repository name", tape :
   operation-day-zero

5. Sélectionne "Public"

6. Clique sur "Create repository"

7. Tu vois ta page de repository vide.
   Clique sur "uploading an existing file"
   (c'est un lien dans le texte au milieu de la page)

8. Fais glisser TOUS les fichiers de ce dossier dans la zone :
   role1.html, role2.html, role3.html,
   role4.html, role5.html, role6.html,
   maitre.html, style.css
   → 8 fichiers au total

9. Clique sur "Commit changes" (bouton vert en bas)

10. Maintenant clique sur l'onglet "Settings"
    (en haut de la page, icône engrenage)

11. Dans le menu à gauche, clique sur "Pages"

12. Dans la section "Branch" :
    → Sélectionne "main" dans le menu déroulant
    → Clique sur "Save"

13. Attends 2-3 minutes puis rafraîchis la page (F5)

14. Tu vois apparaître une URL verte en haut, du type :
    https://kais-odz.github.io/operation-day-zero/

    ⚠️ C'EST L'URL DE TON JEU — note-la précieusement !

Sur ton PC, ouvre Chrome et teste ces URLs
(remplace "kais-odz" par TON pseudo GitHub) :

  https://kais-odz.github.io/operation-day-zero/role1.html
  https://kais-odz.github.io/operation-day-zero/maitre.html

POUR TESTER LA SYNCHRONISATION :
1. Ouvre maitre.html dans un onglet Chrome
2. Ouvre role1.html dans un autre onglet
3. Clique sur "LANCER LE JEU" dans maitre.html
4. L'écran de déverrouillage doit apparaître
   automatiquement sur role1.html dans les 2 secondes

Si ça marche → tu es prêt pour le jour J !

LE JOUR DU JEU — DEROULEMENT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Connecte tous les PC au même WiFi
   (ta box 4G ou ton routeur Free)

2. Sur chaque PC joueur, ouvre Chrome et tape l'URL :
   URL/role1.html  (PC1)
   URL/role2.html  (PC2)
   URL/role3.html  (PC3)
   URL/role4.html  (PC4)
   URL/role5.html  (PC5)
   URL/role6.html  (PC6)

3. Sur TON PC, ouvre Chrome et tape :
   URL/maitre.html

4. Lance la vidéo d'introduction ARES-7

5. Clique sur "LANCER LE JEU" dans ta console

6. Les 6 écrans basculent automatiquement
   sur l'écran de déverrouillage

7. Le jeu commence — 57 minutes !

8. Quand la synchronisation est complète (6/6),
   dis aux joueurs d'ouvrir la boîte
   → Clique sur "DECLENCHER L'APPEL"
   → Appelle le téléphone caché dans la boîte
   → Dicte le code : 4 - 8 - 2 - 6 - 1 - 9

PROBLEMES FREQUENTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

PROBLEME : La page ne charge pas / erreur 404
SOLUTION : Attends 5 minutes après l'étape A.
           GitHub Pages met parfois du temps a activer.

PROBLEME : Page blanche ou erreur Firebase
SOLUTION : Vérifie que tu as bien uploadé LES 8 FICHIERS
           (les 7 HTML + style.css). S'il manque style.css
           la page perd son style mais devrait fonctionner.

PROBLEME : Les PC ne se synchronisent pas
SOLUTION : Vérifie que tous les PC sont connectés
           au même WiFi. Rafraîchis les pages (F5).

PROBLEME : Le jeu ne se lance pas depuis maitre.html
SOLUTION : Verifie sur console.firebase.google.com que
           Realtime Database est bien active en mode test.
